# Vision

## Pourquoi
Tendre vers plus d'autonomie alimentaire en combinant plusieurs techniques de culture
(hydroponie, aquaponie, pleine terre…), pilotées et suivies par de l'électronique
open-source maison.

## Objectifs (à affiner ensemble)
- [ ] Premier système hydroponique fonctionnel et instrumenté
- [ ] Supervision centralisée (mesures, alertes, historique)
- [ ] Aquaponie
- [ ] Étendre aux cultures en terre / serre

## Principes
- **Sécurité d'abord** : eau + 230V.
- **Autonomie locale** : chaque nœud reste sûr et fonctionnel sans réseau.
- **Reproductible** : tout ce qui est construit est documenté (BOM, schémas, sources CAD, firmware).
- **Itératif** : prototype simple → mesure → amélioration.
