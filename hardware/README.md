# Hardware électronique

- `nodes/` : cartes ESP32 (schémas KiCad, PCB, câblage)
- `sensors/` : capteurs (pH, EC, température eau/air, humidité, niveau, O2 dissous…), notes d'intégration et calibration
- `actuators/` : pompes, électrovannes, relais, éclairage, aérateurs
- `power/` : alimentation, protections
- `bom/` : nomenclatures (CSV) avec prix et fournisseurs
- `datasheets/` : liens ou PDF des fiches techniques
