# Mécanique & impression 3D

- `cad/` : **sources** (OpenSCAD/FreeCAD/…) — toujours versionner la source, pas seulement le STL
- `stl/` : exports imprimables (générés depuis `cad/`)
- `print-profiles/` : réglages slicer (matériau, remplissage…). Pour le contact eau/plantes : PETG ou ASA plutôt que PLA.
